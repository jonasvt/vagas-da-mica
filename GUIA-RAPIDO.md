# Bot de Vagas — guia rápido

O bot procura **vagas remotas** que aceitam quem está no Brasil e posta as vagas novas no **seu canal** do servidor.

**1. Receber vagas novas no seu canal**

Entre no seu canal (ex.: `#vagas-micaelly`) e digite:
```
/alerta python, backend, engenheiro de dados
```
Pronto: toda vaga nova com essas palavras aparece nesse canal, sozinha.
Tem um campo opcional **sem** para o que você não quer no título. Exemplo: `senior, lead, estágio`.

**2. Procurar agora**
```
/vagas python, cientista de dados
```
(a resposta só você vê)

**3. Ver ou apagar alertas**
```
/alertas
/apagar 3
```

**Dicas**
- Vírgula separa as opções: `python, dados` = vagas com python **ou** dados.
- Escreva em português e em inglês para achar mais: `cientista de dados, data scientist`.
- Viu uma vaga boa no Discord? **Encaminhe** para o bot (conversa com ele). No LinkedIn: cole o link do post + o texto.
- Esqueceu? `/ajuda`.
